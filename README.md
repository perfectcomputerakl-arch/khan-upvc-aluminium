# KHAN UPVC & ALUMINIUM WORK — Website

Static responsive business website with design gallery, service sections, estimate calculator, live SVG preview, sample reviews, completed-project placeholders and WhatsApp enquiries.

## Run locally
Open `index.html` in a browser, or deploy the folder to any static hosting provider.

## Before publishing
1. Replace the illustrative Gallery image URLs in `index.html` with your own licensed/real project photos.
2. Replace the three Completed Projects placeholders with actual project photographs.
3. Replace demo customer reviews only with genuine reviews shared with customer permission.
4. Update every sample rate in the Rate Master section to your actual business rates. Rates are illustrative and are not a binding quotation.
5. Confirm business address and contact details.

## Features
- Responsive horizontal swipe gallery with category filters.
- WhatsApp enquiry button on every gallery design.
- UPVC / Aluminium window and door estimate controls.
- Sliding, openable, balcony and French door types; single/double shutter.
- Glass partition and building facade estimate options.
- Live dimension labels and illustrative SVG preview.
- Editable local-browser sample rate master.
- Print / Save PDF estimate.
