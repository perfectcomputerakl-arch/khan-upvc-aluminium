# KHAN UPVC & Aluminium Website

Static website package — GitHub Pages / Cloudflare Pages friendly. No build command or backend required.

## Files
- `index.html` — website structure and calculator
- `style.css` — responsive styling
- `app.js` — live preview, estimator, rate master and WhatsApp enquiry

## Upload to GitHub
1. Extract this ZIP on your computer/mobile.
2. Open your GitHub repository.
3. Upload **all files inside** this folder (not the ZIP itself) to the repository root.
4. Ensure `index.html`, `style.css`, `app.js` are at the root level.
5. For GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## IMPORTANT: Set actual rates before publishing
Open the website → scroll to **Admin Rate Settings** → replace the demo profile, glass, mesh, hardware, installation and transport rates with your actual rates → Save rates.
Rates are stored in that browser's localStorage only. They are not synced to visitors or other devices. This calculator is an estimate, not a fabrication/CAD production drawing or final quotation. The formulas are starter estimates and must be calibrated to your cutting list, profile consumption, reinforcement, gaskets, rollers, locks, screws, wastage, taxes and local labour costs.
